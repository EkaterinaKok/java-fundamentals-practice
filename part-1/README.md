# Часть 1: Основы Java (Java Core Basics)
Этот модуль посвящен освоению базового синтаксиса и фундаментальных концепций платформы Java, необходимых для уверенного написания программ и понимания механики работы языка.

### 🎯 Ключевые темы практикума:
* **Синтаксис и управляющие конструкции:** Инициализация переменных, примитивные типы данных, системы счисления, циклы и ветвления (`if-else`, `switch`, `ternary`).
* **Базовое ООП:** Структура классов, создание объектов, перегрузка конструкторов и методов, управление ключевым словом `this`, основы работы с памятью.
* **Инкапсуляция и доступ:** Организация кода по пакетам (`package`), импорт, использование модификаторов видимости (`public`, `protected`, `default`, `private`) и финальных/статических констант.
* **Базовые структуры данных и API:** Работа со строками (`String`, `StringBuilder`), массивы, динамические списки (`ArrayList`) и понимание работы сборщика мусора (Garbage Collection).
* **Знакомство с продвинутыми механизмами:** Основы обработки исключений (`try-catch`), базовые лямбда-выражения, Date & Time API и первое знакомство с дженериками (Generics).

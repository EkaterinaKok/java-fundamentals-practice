# 📋 Список практических задач

Ниже представлена интерактивная карта задач первой части курса:


## ✏️ Задача 1: Форматированный вывод текста (Рубаи)
* **Цель:** Отработка базовых методов консольного вывода `System.out.print()` и `System.out.println()`, контроль переносов строк и отступов.
* **Условие:** Вывести на дисплей рубаи (четверостишие) Омара Хайяма, строго соблюдая все авторские отступы и центрирование заголовка/автора.
  
Ожидаемый вывод в консоли:
```text
               РУБАИ
Много лет размышлял я над жизнью земной.
Непонятного нет для меня под луной.
Мне известно, что мне ничего не известно!
Вот последняя правда, открытая мной.
                                О. Хайям
```
* **Точка входа (Main класс):** [`com.ekaterinakok.javabasics.task1.QuatrainPrinter`](./src/main/java/com/ekaterinakok/javabasics/task1/QuatrainPrinter.java)

## ✏️ Задача 2: Литералы и типы данных (Системы счисления)
* **Цель:** Изучение целочисленных и вещественных типов данных в Java, запись числовых литералов в различных системах счисления (десятичной, двоичной, восьмеричной, шестнадцатеричной) и работа с логическим и символьным типами.
* **Условие:**  
  1\. Создать по 4 переменные типов `byte`, `short`, `int`, `long`. Каждая группа должна принимать заданное значение (12, -1300, 0, 123456789 соответственно), но записываться в четырёх разных системах счисления. Вывести их на экран.  
  2\. Создать по 2 переменные типов `float`, `double`, `boolean`. Вывести их на экран.  
  3\. Создать несколько переменных типа `char` всеми возможными способами (символ, Unicode-код, целочисленный код). Вывести их на экран.

* **Точка входа (Main класс):** [`com.ekaterinakok.javabasics.task2.DataTypesDemo`](./src/main/java/com/ekaterinakok/javabasics/task2/DataTypesDemo.java)
